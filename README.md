# Auctionator Plus

A companion add-on for [Auctionator](https://www.curseforge.com/wow/addons/auctionator) that adds three tools to the Auction House.

## Features

- **Price-history tooltips** — hover any item while the Auction House is open to see *Average Min. Buyout*, *Trend*, *Highest Day*, and *Lowest Day*. Stays out of the way inside the buy detail and sell-item views.
- **Stat Finder** — type comma-separated stats like `agility, stamina, dps` and only items matching every term are shown. Works in any locale; common English aliases map to your client's localized stat names automatically.
- **Flip Finder** — surfaces items whose lowest auctions span a price gap above your configured margin, with filters for relative order quantity, listings depth, investment, and ROI.

## Usage

1. Run a shopping-list search in Auctionator.
2. Hover an item to see its price history.
3. Click **Stat Finder** to filter the results by item stats.
4. Click **Flip Finder** to surface profitable flips.
5. Click any row to inspect the item in Auctionator.

Both panels and the tooltip block share the data Auctionator already collected — no extra scanning needed.

## Requirements

- WoW Retail (Midnight) or Classic Era 1.15.x
- [Auctionator](https://www.curseforge.com/wow/addons/auctionator)
